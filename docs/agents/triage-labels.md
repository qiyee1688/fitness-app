# Triage Labels / 分诊标签

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

这些 skills 使用 5 个标准分诊角色。本文件把这些角色映射到当前仓库 issue tracker 中实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | Meaning | 中文含义 |
| --- | --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue | 需要维护者评估 |
| `needs-info` | `needs-info` | Waiting on reporter for more information | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent | 需求完整，agent 可直接实现 |
| `ready-for-human` | `ready-for-human` | Requires human implementation | 需要人类实现 |
| `wontfix` | `wontfix` | Will not be actioned | 不处理 |

When a skill mentions a role, use the corresponding label string from this table.

当 skill 提到某个分诊角色时，使用本表中对应的标签字符串。
