## Agent skills / Agent 技能配置

### Issue tracker / Issue 跟踪器

Issues and PRDs are tracked in GitHub Issues for `qiyee1688/fitness-app`.

本项目的 Issue 与 PRD 统一发布到 `qiyee1688/fitness-app` 的 GitHub Issues。

See `docs/agents/issue-tracker.md`.

### Triage labels / 分诊标签

Use the default Matt Pocock skills triage labels.

使用 Matt Pocock skills 的默认分诊标签。

See `docs/agents/triage-labels.md`.

### Domain docs / 领域文档

This repo uses a single-context domain docs layout: root `CONTEXT.md` plus `docs/adr/`.

本仓库使用单上下文领域文档布局：根目录 `CONTEXT.md` 加 `docs/adr/`。

See `docs/agents/domain.md`.
